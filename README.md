# AI-Powered Clinical Operations & Patient Triage Platform

Multi-agent clinical operations platform with patient/doctor portals, 
symptom-based triage, appointment scheduling, hardcoded safety guardrails, 
RAG-based medical guidelines copilot, and human-in-the-loop approval.

## Tech Stack
- Frontend: Next.js / React
- Backend: Python + FastAPI
- Agent Orchestration: LangGraph
- Database: PostgreSQL + pgvector
- Cache/Queue: Redis
- Containers: Docker / Docker Compose
